Major district georeferencing

Align the licensed Vaasa major-district SVG with OpenStreetMap, then register matching control points. Copy the generated JSON and send it back for reproducible SVG-to-GeoJSON conversion. Return to the main map.

1. Align the SVG overlay

Drag the four orange corner handles until coastlines, islands and district positions match the basemap. Zooming and panning the map does not change the saved bounds.

Four corners ready

Source artwork: Vaasa major districts map by Tvinnari, licensed CC BY-SA 4.0. The resulting coordinates are derived reference data, not official municipal survey geometry.

2. Add matching control points

Click a recognizable location in the SVG pane, then click the same physical location on OpenStreetMap. Use coast tips, bridge endpoints, harbour structures, road intersections or other unambiguous points spread across the full map.
